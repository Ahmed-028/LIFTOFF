# Flight artwork

Earth, Moon and Mars maps by [Solar System Scope](https://www.solarsystemscope.com/textures/), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The game uses these maps on rotating 3D spheres.

Moon and Mars terrain backdrops were generated with the built-in ImageGen tool and resized to JPEG. Prompts:

- Create a wide 16:9 game environment plate for LIFTOFF, a child-friendly educational space game. Moon: charcoal-gray cratered lunar surface, angular rock ridges and distant rugged hills, sunlight from upper right, black star-filled sky. Cinematic stylized-realistic 3D game rendering, clear large shapes, foreground flat enough for compositing an animated lander or rover, distant horizon about 52 percent down the image. Keep the center clear. Environment only, no spacecraft, people, text, or interface.
- Create a wide 16:9 game environment plate for LIFTOFF, a child-friendly educational space game. Mars: rust-orange rocky Martian plain, red layered ridges and dusty salmon atmosphere with distant cliffs. Cinematic stylized-realistic 3D game rendering, clear large shapes, foreground flat enough for compositing an animated lander or rover, distant horizon about 52 percent down the image. Keep the center clear. Environment only, no spacecraft, people, text, or interface.

# NASA visual assets

Source collection and usage guidance: [NASA 3D Resources](https://github.com/nasa/NASA-3D-Resources).

The in-game OBJ variants use simplified geometry from the NASA source models.
They have flat game materials and are scaled for the hangar. Game dimensions,
power, mass and costs come from the mission catalog.

| In-game asset | NASA source folder |
| --- | --- |
| nasa-eo1.obj | [Earth Observing-1](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Earth%20Observing-1%20%28EO-1%29) |
| nasa-landsat7.obj | [Landsat 7](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Landsat%207) |
| nasa-sorce.obj | [SORCE](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Solar%20Radiation%20and%20Climate%20Experiment%20%28SORCE%29) |
| nasa-apollo.obj | [Apollo Lunar Module](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Apollo%20Lunar%20Module) |
| nasa-ingenuity.obj | [Ingenuity](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Ingenuity%20Mars%20Helicopter) |
| nasa-perseverance.obj, nasa-mastcam.obj, nasa-pixl.obj, nasa-rimfax.obj | [Perseverance](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Mars%202020%20Perseverance%20Rover) |

The JPEGs in `art/nasa` are resized NASA preview renders of Earth Observing-1,
Landsat 7, Aqua (A), Terra, TRMM, ICESat (A), Lunar Reconnaissance Orbiter (A),
and Perseverance. Supplies labels these as host spacecraft and labels the
original representative instrument diagrams separately. NASA/JPL-Caltech
credits apply to Perseverance and Ingenuity.
